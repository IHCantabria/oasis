# Group 9: Integration & Solvers

Compares ODE time integration solvers on an identical physical problem. All four examples use the same cable, boundary conditions, and excitation — the only difference is the solver algorithm (and order, for BDFN).

## Physical Setup

A 10 m cable hanging from two endpoints at the same height (z = 0), separated by 8 m horizontally (0.8 × L). One end is fixed (anchor at the origin), the other is driven in a circular motion in the XZ plane.

```
      Actuator (circular motion)
         O ← R=1m, T=10s
        /|
       / |
  ~~~~/  |~~~~  cable (catenary sag)
     /   |
    O----+
  Anchor
  (0,0,0)      (8,0,0)
```

### Cable Properties

| Parameter | Value | Unit |
|---|---|---|
| Length (L) | 10.0 | m |
| Axial stiffness (EA) | 1×10⁷ | N |
| Weight per unit length | 20.0 | kg/m |
| Diameter | 0.05 | m |
| Internal damping (β) | 0.01 | — |
| Tension model | symmetric | — |
| Nodes | 6 | — |

### Actuator Motion

Circular motion in the XZ plane centered at (8, 0, 0):
- Radius: R = 0.5 m
- Period: T = 10 s
- Smooth half-cosine ramp over 20 s (2 full periods)

$$x(t) = 8 + R \sin(\omega t) \cdot \text{ramp}(t)$$
$$z(t) = R (\cos(\omega t) - 1) \cdot \text{ramp}(t)$$

where $\omega = 2\pi/T$ and $\text{ramp}(t) = \frac{1}{2}\left(1 - \cos\left(\frac{\pi t}{T_{\text{ramp}}}\right)\right)$ for $t < T_{\text{ramp}}$, else 1.

Velocities and accelerations are computed analytically (product rule). The actuator data file is generated by `generate_actuator_motion.py`.

## Solver Configurations

All examples share: dt = 0.002 s, T_sim = 50 s, fixed stepping, abs_tol = 1e-5, rel_tol = 1e-3, max_iter = 50, Jacobian recomputed every step.

| Example | Solver | `timeIntMethod` | `timeIntOrder` | Description |
|---|---|---|---|---|
| `bdf1` | BDF1 | 1 | — | 1st-order BDF (auto-promotes to 2nd order) |
| `bdfn_order2` | BDFN | 2 | 2 | Multi-step BDF, 2nd order |
| `bdfn_order4` | BDFN | 2 | 4 | Multi-step BDF, 4th order |
| `esdirk46` | ESDIRK46 | 3 | — | Explicit singly diagonal implicit Runge-Kutta (4th/6th order embedded) |

## Generating Actuator Data

Before running the examples, generate the prescribed motion files:

```bash
cd examples/solvers
python generate_actuator_motion.py
```

This creates `dataActuator_0.dat` in each example's `input/` directory with 50001 time steps (dt = 0.001 s).

## Running

```bash
# All solvers
cd examples/solvers
run_group.bat               # Windows
sh run_group.sh             # Linux

# Single solver
cd examples/solvers/esdirk46
run.bat                     # Windows
sh run.sl .                 # Linux
```

## Expected Behavior

- All solvers should complete without errors on this well-posed problem
- The ramp ensures a smooth start with no initial transients
- After ramp-up (t > 20 s), the cable reaches periodic steady-state oscillation
- Higher-order solvers (BDFN order 4, ESDIRK46) should show smoother time histories and better energy conservation
- BDF1 (effectively 2nd order) and BDFN order 2 should produce very similar results

## What to Compare

- Line tension at anchor and actuator nodes
- Midpoint displacement trajectory
- Computational cost (wall-clock time from OASIS output)
- Convergence: number of Newton iterations per time step
