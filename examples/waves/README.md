# Group 2: Wave Types

This group tests all wave input types and options supported by OASIS. Each example uses a **locked body** with 1st-order excitation as a wave "sensor", isolating wave generation from other dynamics.

## Examples

| # | Example | Wave Type | Key Feature |
|---|---------|-----------|-------------|
| 1 | `regular/` | REG | Regular sinusoidal wave: H=2 m, T=10 s, heading=0°, ramp=5 s |
| 2 | `jonswap/` | IRR (specType=1) | JONSWAP spectrum: Hs=1.5 m, Tp=10 s, γ=3.3, unidirectional, no piecewise |
| 3 | `jonswap_piecewise/` | IRR (specType=1) | Same JONSWAP with piecewise decomposition (`piecewise_flag=1`) for faster diffraction |
| 4 | `multidirectional/` | IRR (specType=1) | JONSWAP with directional spreading: s=2.0 (cos⁴ distribution), dθ=10° |
| 5 | `timeseries/` | IRR (specType=2) | Pre-generated time-series from `wave.dat` (JONSWAP-based, 1000 s, dt=0.1 s) |
| 6 | `frequency_domain/` | IRR (specType=3) | Frequency-domain components from `wavefreq.dat` (two sea states, multi-heading) |

## Wave Types Reference

### Regular waves (`REG`)
A single sinusoidal wave defined by height, period, heading, and an optional ramp time.

### Irregular waves (`IRR`)
Irregular sea states support three spectrum input modes:

- **specType=1 (JONSWAP)**: Analytically generated JONSWAP spectrum. Supports directional spreading via parameter `s` (cos²ˢ spreading function). When `s < 1`, waves are unidirectional.
- **specType=2 (Time-Domain)**: Read a pre-generated wave elevation time series from file. OASIS performs FFT internally to extract components.
- **specType=3 (Frequency-Domain)**: Read individual frequency components (freq, heading, amplitude, phase) directly. Supports multi-directional sea states with arbitrary heading distributions.

### Piecewise decomposition (`piecewise_flag`)
When enabled, the wave spectrum is split into time segments for memory-efficient diffraction force computation. Only applicable to specType=1 and specType=2.

## Data Generation Scripts

The time-series and frequency-domain input files are generated by Python scripts in `resources/`:

- `generate_wave_timeseries.py` → generates `wave.dat` (JONSWAP time series, Hs=1.5 m, Tp=10 s)
- `generate_wave_freq.py` → generates `wavefreq.dat` (two JONSWAP systems at different headings)

To regenerate:
```bash
cd <oasis_root>
python resources/generate_wave_timeseries.py examples/waves/timeseries/input/wave.dat
python resources/generate_wave_freq.py
mv wavefreq.dat examples/waves/frequency_domain/input/wavefreq.dat
```

## Common Setup

All examples share:
- **Body**: Locked (`body_freedom=1`), 1st-order excitation, `isobara.ehydb` database
- **Duration**: 300 s (long enough for reliable irregular wave statistics)
- **Integrator**: ESDIRK46 (method=3, order=2), dt=0.1 s
- **Water depth**: 500 m
