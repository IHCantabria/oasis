
# OASIS 
Oasis (Offshore Advanced SImulation Software) is a numerical model for the simulation of offshore floating structures, implemented with C++ by IHCantabria.
It is based in potential flow hydrodynamics and including several features like:
- Non-linear restoration and Froud-Krylov hydrostatic forces.
- Dynamic mooring lines with high order Finite Elements Method, capable to adapt to irregular bathymetries.
- Wind turbine modelling through coupling with openFAST.
- Fast second order wave excitation forces with optimized QTFs.
- Morison coefficients model for current drag and non-linear viscous forces calibration.
- Versatile model for connector and fenders to simulate contact between bodies
